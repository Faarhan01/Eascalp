# AdvancedScalpingEA v2.3.0 — System Architecture

## 1. Design Philosophy & Isolation Guarantees
AdvancedScalpingEA v2.3.0 is engineered as a modular, self-tuning MetaTrader 5 quantitative multi-market scalping Expert Advisor requiring zero external `.set` preset files. Its primary invariants are:
1. **Ready-to-Trade Execution Across Live, Demo & Strategy Tester**: `InpOperatingMode` defaults to `EA_MODE_LIVE_TRADING`, `InpAllowLiveTrading = true`, and `InpConfirmLiveRiskAcknowledgement = true`. `TradeValidation.mqh` enforces `TERMINAL_TRADE_ALLOWED` strictly in live/demo runtime while evaluating `MQL_TRADE_ALLOWED` in `MQL_TESTER` so backtests run reliably out of the box.
2. **Zero-Preset Universal Symbol Auto-Profiler (`SymbolIntelligence.mqh`)**: Automatically classifies Forex Majors, Minors/Crosses, Exotics (including unseparated broker suffixes like `EURUSDm`/`XAUUSDpro`), Metals, Energies, Stock Indices, Crypto CFDs, Step Index (`ASSET_SYNTHETIC`, quantized step protection), and Volatility/Crash-Boom/Jump synthetics via symbol tokens, `SYMBOL_CURRENCY_BASE`/`PROFIT`, `SYMBOL_PATH`, `SYMBOL_SECTOR`, and `SYMBOL_TRADE_CALC_MODE`. `GetAdaptiveAssetProfile()` returns tailored `SAdaptiveAssetProfile` SL/TP ATR multipliers, BE/trailing thresholds, ADX regime thresholds, spread/volatility bounds, post-loss cooldown bars, and `minSignalScore` without `.set` presets (`InpAutoAdaptBySymbol = true`).
3. **Strict Read-Only Dashboard Isolation & Non-Visual Tester Acceleration**: `CDashboardManager` accepts only `const SDashboardSnapshot`, `const SManagedPosition[]`, and curve/breakdown arrays, and skips `OnTimer()` / snapshot copying completely in non-visual Strategy Tester runs (`MQL_TESTER && !MQL_VISUAL_MODE`).
4. **Zero Look-Ahead / Zero Repainting**: Indicators (`IndicatorEngine.mqh`, `MultiTimeframe.mqh` using dynamic `ArraySetAsSeries(..., true)` buffers), market structure (`MarketStructure.mqh`), candlestick formations (`CandlestickRecognition.mqh`), and geometric chart patterns (`PatternRecognition.mqh`) evaluate completed bars (`shift >= 1`) exclusively, using closed-bar entry evaluation by default (`InpEvaluateOnNewBarOnly = true`).
5. **Magic-Number Ownership Isolation**: `CPositionManagement` and `CPerformanceAnalytics` strictly filter `PositionsTotal()` and `HistoryDealsTotal()` by `POSITION_MAGIC == m_magic` and `DEAL_MAGIC == m_magic`.

## 2. Module Dependency Layers (v2.3.0)
- **Core**: `Types.mqh` (`SAdaptiveAssetProfile`, `SSymbolProfile`), `Diagnostics.mqh`, `StateManager.mqh` (schema v2), `SymbolContext.mqh` (isolated per-symbol container supporting up to 8 symbols with per-asset regime thresholds), `EAController.mqh` (per-symbol post-loss cooldowns, directional consensus, opposing-conflict chop guard, live-price anti-chase guard)
- **Market**: `SymbolIntelligence.mqh` (universal asset & Step Index auto-profiler, `SAdaptiveAssetProfile` self-tuning engine, hedging/netting detection, auto-adaptive spread/slippage limits, `OrderCalcProfit` fallback, historical commission inspection), `MarketData.mqh`, `TickAnalysis.mqh`, `MarketStructure.mqh`, `MarketRegime.mqh` (17 granular market regimes + transition detection), `MultiTimeframe.mqh` (dynamic series-indexed MTF trend alignment)
- **Indicators**: `IndicatorEngine.mqh` (ATR(5)/ATR(14)/ATR(40), session VWAP with rolling 48-bar fallback for 24/7 synthetics/Step Index, volatility percentile, StdDev, momentum acceleration, RSI divergence, exhaustion), `CandlestickRecognition.mqh`, `PatternRecognition.mqh`
- **Strategies**: `StrategyBase.mqh` (`GetEffectiveSlMult()`, `GetEffectiveTpMult()`, `ComputeStructuralSLDist()`, `GetRegimeSuitability()`, `ShouldExitPosition()`), plus all 7 independent strategies (`TrendPullback`, `MomentumScalping`, `BreakoutScalping`, `ReversalScalping`, `RangeScalping`, `VolatilityExpansion`, `MicroMomentum`)
- **Trading**: `ExpectancyEngine.mqh` (cost-aware R:R >= 1.30 & per-asset TP:Cost filtering), `SignalScoring.mqh` (10-component 0–100 score + counter-HTF penalty + session VWAP confluence + `ApplyMultiStrategyConsensus()`), `TradeValidation.mqh` (12-gate validator with adaptive asset profile limits), `RiskManagement.mqh` (equity-DD & streak anti-Martingale throttling, margin-safe lot clamping, portfolio open risk & Forex currency exposure caps), `TradeExecution.mqh` (3-mode IOC/FOK/RETURN fallback, adaptive slippage), `PositionManagement.mqh` (>= 1.0R cost-covering Break-Even, partial close min-lot guard, tiered progressive Chandelier trailing, multi-factor CHoCH exit, optional Friday close)
- **Intelligence**: `StrategySelection.mqh` (overall & per-regime benching of losing strategies), `AdaptiveLearning.mqh` (5-stage controlled pipeline), `HistoricalResearch.mqh` (OOS split tagging, score-band metrics, deterministic Monte Carlo drawdown)
- **Analytics**: `Statistics.mqh`, `PerformanceAnalytics.mqh`, `CSVLogger.mqh` (12 buffered CSV files)
- **Dashboard**: `DashboardComponents.mqh`, `DashboardLayout.mqh`, `DashboardCharts.mqh`, `DashboardStatistics.mqh`, `DashboardManager.mqh`

## 3. State Recovery on Terminal Restart
`CStateManager` (`schemaVersion = 2`) persists daily/weekly balance anchors, peak equity/balance, consecutive loss counters, lockout status, active/validated config versions, and observation counters into `MQL5/Files/AdvancedScalpingEA/State/state_<symbol>_<magic>.ini`. On startup, `CEAController` restores those anchors and reconciles open positions (`partialExitTaken`, MFE/MAE, exit tracking) and historical closed deals directly from MT5 terminal state.
